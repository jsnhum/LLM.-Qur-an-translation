# LLM translations of the Qur'an

This repository contains complete English translations and interpretations of the Qur'an generated by large language models (LLMs), verse by verse, without any human editing. Each file covers all 6236 verses.

The 2024 translations are analysed in:

> Svensson, Jonas (forthcoming), "Machines translating the Qur'an: A comparative analysis of AI and human generated translations".

The full 2024 dataset is also archived as QAHA – Qur'anic Artificial Hermeneutics Archive (Svensson 2026, Zenodo, https://doi.org/10.5281/zenodo.19048553).

## Method

- **Source text:** the unvoweled Arabic text of the Qur'an from [tanzil.net](https://tanzil.net) ("simple clean").
- **Procedure:** one request per verse, sent via each provider's API. No context from surrounding verses was given.
- **Prompt** (translate and interpret):

  > You are a very able interpreter of the Qur'an. Given a verse from the Qur'an in Arabic, you will translate the given verse, and then give your interpretation on its meaning. Give only one interpretation. Provide only the interpretation, not a summary of the content of the verse.

- **Editing:** none. The outputs are published exactly as delivered by the models, including errors and hallucinations.

### Cost

The collection is run on a small research budget, so model choice is limited by price:

- **Price limit:** only models priced at $15 or less per million output tokens are used at this point. This excludes the current flagship models of most companies.
- **Batch mode** (about half price) is used where the provider offers it.
- **Reasoning:** reasoning tokens are billed as output and can multiply the cost of a run. From Claude Sonnet 5.5 onwards the reasoning level is set to `low`. Earlier runs used the provider's default. For Claude Sonnet 5 this was an oversight: its default reasoning made the run about three times as expensive as projected.

## Differences between the two collections

- **Common columns:** `chapter`, `verse`, `translation` and `interpretation` are present in both formats, so the files can be read together by column name.
- **Arabic text:** included only in the 2024 files (`orig`). The newer files can be joined with the tanzil text on `chapter` and `verse`.
- **Model and run information:** in the 2024 files, the model is given only by the filename and the table above. The newer files record the model ID, status, number of attempts, reasoning level and reasoning tokens for each verse.
- **Encoding:** the newer files start with a byte order mark (BOM) for compatibility with Excel. Read them with `encoding="utf-8-sig"` in Python.
